# NK Deal Website

Static HTML/CSS site for NK Deal Food Distribution.

## XAMPP
1. Extract the contents of this folder into `htdocs/nkdeal/`.
2. Start Apache in XAMPP.
3. Open `http://localhost/nkdeal/`.

## GitHub Pages
Upload the contents of this folder to the root of the GitHub Pages repository. No build step is required. The site uses relative asset paths so it works both at a local XAMPP subfolder and at a GitHub Pages project URL.

`CNAME` is included for the custom domain configuration.
